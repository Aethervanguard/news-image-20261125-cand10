## How it runs

`main.py` (Python 3.13, standard library only) copies the pre-rendered `entry.png` (1024×1024, under 1 MiB) to `$MAKEFUN_OUTPUT_DIR/entry.png`. The program is deterministic: it writes the same bytes on every run, with no network access.
